INFINITE AI POLICY PAGES — SETUP

Before publishing:
1. Replace every occurrence of REPLACE-WITH-A-CONTACT-EMAIL in terms.html and privacy.html with an email address you monitor.
2. Read the privacy policy carefully and make sure the statements match your actual implementation, especially token storage, temporary video deletion, logs and retention. Edit anything that is not true.
3. These pages are a starting draft, not legal advice or a guarantee that TikTok will approve the app.

GitHub Pages quick setup:
1. Create a NEW public repository, e.g. infinite-ai-legal.
2. Upload index.html, terms.html, privacy.html to the repository root.
3. In repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
4. Wait for GitHub Pages to publish the site.
5. Your links will be:
   https://YOUR-GITHUB-USERNAME.github.io/infinite-ai-legal/terms.html
   https://YOUR-GITHUB-USERNAME.github.io/infinite-ai-legal/privacy.html
   Replace YOUR-GITHUB-USERNAME and repository name with your actual values.
6. Open both links in a private/incognito browser window to verify they work without signing in.
7. Paste the real URLs into TikTok's Terms of Service URL and Privacy Policy URL fields.

Do not put API keys, OAuth client secrets, refresh tokens, or .env files in this repository.
